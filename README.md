# reverse-lab

每日自动**逆向拆解 GitHub 1000+ star 项目**的归档仓库。

由 WorkBuddy 自动化任务驱动：每天 08:00（Asia/Shanghai）自动执行——

1. 从 GitHub Trending 挑选一个 1000+ star 项目（优先 TS/JS 前端生态，自动避开已拆解过的）
2. 浅克隆后阅读 README、依赖清单、目录结构与核心模块源码
3. 产出逆向研报（架构图 / 数据流 / 技术亮点 / 可借鉴设计）与关键源码解析，时间允许时附最小复现

## 目录结构

```
YYYY-MM-DD-<项目名>/
├── README.md      # 逆向研报
├── notes/         # 关键源码逐段解析
└── mini-repro/    # 最小可运行复刻（时间允许时）
```
